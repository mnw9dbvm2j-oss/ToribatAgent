사용자가 직접 담당할 파트는 OFF로 두세요. OFF된 에이전트와 관련된 태스크는 자동 실행에서 보류됩니다.

🎯 결과물 품질 기준

모든 결과물은 목표, 적용 위치, 실제 산출물, 구현 방법, 테스트 방법, 다음 태스크를 포함해야 합니다. 빈약한 결과물은 실패/품질 확인 필요로 처리됩니다.
